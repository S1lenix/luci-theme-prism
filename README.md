# Prism

**Русский** | [English](README.en.md)

Prism - тема для веб-интерфейса OpenWrt LuCI с восемью стилями оформления и плавными анимациями. Адаптивная навигация, формы, таблицы и индикаторы сохраняют единый вид на компьютере и телефоне.

[Скачать](https://github.com/S1lenix/luci-theme-prism/releases/latest) | [Сообщить об ошибке](https://github.com/S1lenix/luci-theme-prism/issues)

## Стили

| Стиль | Описание |
| --- | --- |
| Light | Светлый интерфейс с синими акцентами. |
| Soft | Мягкая светлая палитра с ненавязчивыми градиентами. |
| Dark | Тёмные поверхности и цветные акценты. |
| Ink | Контрастные контуры, почти квадратные формы и яркие индикаторы. |
| Bento | Тёплые оттенки, округлые карточки и оранжевые акценты. |
| Minimal | Простые формы, тонкие линии и минимум декоративных элементов. |
| Retro 98 | Оформление в духе Windows 95/98 с объёмными рамками и сегментными индикаторами. |
| Depth | Тёмная синяя палитра с тенями и объёмными поверхностями. |

Стиль переключается кнопкой палитры в шапке и сохраняется в браузере. Анимации учитывают системную настройку уменьшения движения.

## Совместимость

Для современной LuCI с шаблонами ucode. Требуется установленная тема Bootstrap. Старые версии LuCI с шаблонами Lua не поддерживаются.

- OpenWrt 25.12 - пакет APK.
- OpenWrt 24.10 - пакет IPK.

Данные роутера и доступные разделы определяются LuCI. Сторонние приложения и сборки прошивки могут иметь особенности оформления. Используйте актуальный браузер.

## Установка

Скачайте пакет для своей версии OpenWrt из [Releases](https://github.com/S1lenix/luci-theme-prism/releases/latest).

**OpenWrt 24.10:** откройте **System > Software > Upload Package**, выберите файл IPK и подтвердите установку.

**OpenWrt 25.12:** загрузка стороннего APK через LuCI доступна не во всех версиях. Если интерфейс сообщает об ошибке подписи, скопируйте файл APK в **/tmp** через WinSCP или SCP и установите по SSH:

```sh
apk add --allow-untrusted /tmp/luci-theme-prism-0.5.0-r1.apk
```

После установки выберите **Prism** в **System > System > Language and Style**, сохраните настройки и обновите страницу с **Ctrl+F5**. Перезагрузка роутера не нужна.

## Обновление

Скачайте новый пакет того же формата и установите поверх существующего тем же способом. Для APK укажите новое имя файла в команде. Обновите страницу с **Ctrl+F5**.

## Удаление

В **System > Software > Installed** найдите **luci-theme-prism** и нажмите **Remove**. При удалении активной Prism интерфейс переключится на Bootstrap. Обновите страницу.

## Обратная связь

Сообщайте об ошибках и предлагайте изменения в [Issues](https://github.com/S1lenix/luci-theme-prism/issues). Укажите версии OpenWrt и LuCI, выбранный стиль и страницу, на которой возникла проблема. Для ошибок оформления приложите скриншот.
