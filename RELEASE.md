# Prism 0.5.0

## Русский

Первый публичный релиз Prism - темы для OpenWrt LuCI с плавными анимациями и восемью стилями оформления.

| Стиль | Описание |
| --- | --- |
| Light | Светлый интерфейс с синими акцентами. |
| Soft | Мягкая светлая палитра с ненавязчивыми градиентами. |
| Dark | Тёмные поверхности и цветные акценты. |
| Ink | Контрастные контуры, почти квадратные формы и яркие индикаторы. |
| Bento | Тёплые оттенки, округлые карточки и оранжевые акценты. |
| Minimal | Простые формы, тонкие линии и минимум декоративных элементов. |
| Retro 98 | Оформление в духе Windows 95/98 с объёмными рамками и сегментными индикаторами. |
| Depth | Тёмная синяя палитра с тенями и объёмными поверхностями. |

Инструкции по установке, обновлению и удалению: [README](https://github.com/S1lenix/luci-theme-prism/blob/main/README.md).
Об ошибках сообщайте в [Issues](https://github.com/S1lenix/luci-theme-prism/issues).

## English

The first public release of Prism, an OpenWrt LuCI theme with smooth animations and eight visual styles.

| Style | Description |
| --- | --- |
| Light | A light interface with blue accents. |
| Soft | A soft light palette with subtle gradients. |
| Dark | Dark surfaces with colorful accents. |
| Ink | Strong outlines, nearly square shapes and vivid status indicators. |
| Bento | Warm tones, rounded cards and orange accents. |
| Minimal | Simple shapes, thin lines and little decoration. |
| Retro 98 | A Windows 95/98-inspired look with beveled borders and segmented progress bars. |
| Depth | A dark blue palette with shadows and layered surfaces. |

Installation, update and removal instructions: [README](https://github.com/S1lenix/luci-theme-prism/blob/main/README.en.md).
Please report bugs in [Issues](https://github.com/S1lenix/luci-theme-prism/issues).
